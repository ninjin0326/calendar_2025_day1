# フロントエンド演習問題

以下の演習問題に沿ってソースコードを修正してください。どの問題から解いても構いません。

**注意**: 解いた問題について [SUBMISSION.md](../SUBMISSION.md) ファイルに説明を記載してください。必要に応じて、スクリーンショットや画面録画を追加して説明してください。**このファイルを元に採点をおこないます。**

スクリーンショットは `command（⌘）+ shift（⇧）+ 3` で、画面録画は `command（⌘）+ shift（⇧）+ 4` で実行できます。

## 問題1. 分類ラベルの追加

### 課題

分類ラベルが不足している

### 要件

既存の分類ラベル（work、private、other）に以下を追加して、プルダウンメニューに表示できるようにする（表示のみで良い）

- customer_visits
- internal_meetings
- external_meetings

### 見積

0.25 時間

## 問題2. ヘッダーの UI 調整

### 課題

場所：Calendar.tsx
カレンダーのヘッダー部分のボタンが左揃えになっている

### 要件

- カレンダーのヘッダー部分のボタン「前」「今日」「次」を中央揃えにする
- カレンダーのヘッダー部分のボタン「予定作成」を右揃えにする

### 見積

0.5 時間

## 問題3. レスポンシブ対応

### 課題

場所：Calendar.css
- カレンダーがレスポンシブ対応に変更していない

### 要件

- 画面の横幅が600pxを下回った際に、カレンダーの横幅を固定化しスクロールで閲覧できるようにする


### 見積

0.5時間

## 問題4. 予定追加の UI/UX 改善

### 課題

予定を追加する際のタイトルが入力必須であることが分かりづらい

### 要件

- タイトルのテキストフォームを入力必須にする属性を追加する
- タイトルが空欄の場合は保存ボタンを押せなくする


### 見積

0.5時間

## 問題5. 予定表示のバグ修正

### 課題

予定の追加時と詳細表示時で日時の表示形式が異なるため揃えたい

### 要件

詳細表示時に入力時と同じ形式（`YYYY/MM/DD hh:mm`）で表示する

### 見積

1時間

## 問題6. 予定削除機能の追加

### 課題

予定の削除ができない

### 要件

- 予定の詳細表示をするダイアログに削除アイコンを追加する
- 削除アイコンを押下した際に削除APIが実行されるようにする

### 見積

1時間
